# Дизайн-система «Архив ОЭЗ Алабуга»

Единый визуальный язык для процесса **«Заявка на доступ к ресурсам»** в 1С:Документооборот 8, ред. 2.1 и для всех цифровых сервисов архива.

## Как подменить цвета на фирменные

Официального брендбука ОЭЗ в этой системе нет — палитра рабочая. Если брендбук появится, меняются **три переменные** в блоке `:root` каждого файла:

```css
--brand:   /* основной цвет */
--brand-2: /* светлый оттенок основного */
--accent:  /* акцент «архив» */
```

**Цвета статусов не трогать.** Зелёный «согласовано» и красный «отклонено» узнаются мгновенно и без чтения — это важнее соответствия фирменному стилю.

## Принципы, на которых всё построено

1. **Статус никогда не передаётся только цветом.** Каждый бейдж содержит текст, каждое письмо — символ. Примерно один мужчина из двенадцати не различает красный и зелёный.
2. **Текстовая версия важнее HTML.** Корпоративная почта режет CSS и отключает картинки. Строка `✅ ✅ 🟡 ⬜ ⬜ ⬜` переживает любой почтовый клиент и читается в уведомлении на телефоне, не открывая письмо.
3. **Всегда конкретный человек и конкретная дата.** «На согласовании» без ответа «у кого и до когда» вызывает ровно тот звонок в архив, ради устранения которого всё затевалось.
4. **Бумага и экран показывают одно и то же.** QR на листе согласования ведёт на ту же страницу, что ссылка в письме.
5. **Тёмная и светлая темы — обе.** Через `prefers-color-scheme` и `data-theme`.

## Данные в примерах

Во всех макетах — **плейсхолдеры**: `0000-00`, `00.00.0000`, «должность, ФИО», «наименование системы». Ни одной выдуманной фамилии, ни одного придуманного номера заявки или фонда. Подставляются реальные значения только из вашей базы.
