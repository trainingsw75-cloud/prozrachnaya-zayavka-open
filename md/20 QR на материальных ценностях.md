# QR и штрихкоды на ТМЦ — рабочий разбор

## 1. Инвентарная маркировка

| Вопрос | Ответ | Статус |
|---|---|---|
| Обязательна ли маркировка ОС | Нет. Методические указания (приказ Минфина № 91н), где это описывалось, утратили силу с введением **ФСБУ 6/2020** (утв. приказом Минфина от 17.09.2020 № 204н). Сам ФСБУ инвентарные номера не регулирует | [ЗАКОН] |
| Кто тогда решает | Организация — учётной политикой и положением об учёте ТМЦ. Номер даёт бухгалтерия при принятии к учёту | [ЛОКАЛЬНЫЙ АКТ] |
| Основные средства | Единица учёта — инвентарный объект; номер уникален и не переиспользуется после выбытия (уточнить срок «карантина» номера у бухгалтерии) | [ЛОКАЛЬНЫЙ АКТ] |
| Малоценное имущество, запасы, спецодежда, расходники | Учитываются как запасы (ФСБУ 5/2019) или списываются на расходы. Инвентарного номера, как правило, нет — маркируется **партия/место хранения**, а не штука | [ЗАКОН] + [ПРАКТИКА] |
| СИЗ и спецодежда | Учёт выдачи — по правилам приказа Минтруда от 29.10.2021 № 766н; личная карточка учёта выдачи СИЗ может вестись электронно (с идентификацией работника и его ЭП) | [ЗАКОН] |
| Способ нанесения | Ярлык, краска, наклейка — способ не нормирован, закрепляется локально | [ПРАКТИКА] |

## 2. Что кодировать в метке

- **Кодируем:** только идентификатор объекта либо ссылку вида `https://<домен>/i/<ID>`. Оптимум — ссылка: телефон открывает карточку без приложения.
- **НЕ кодируем — и почему:**

| Нельзя | Причина |
|---|---|
| ФИО держателя, табельный номер, кабинет | Персональные данные (152-ФЗ). Метку видно всем, её фотографируют |
| Стоимость | Инвентаризационная и рыночная цена расходятся; наклейка становится «ценником» для воров |
| Наименование и модель | Устаревает при замене/ремонте; перепечатывать метку дороже, чем поправить карточку |

**Рекомендуемый формат ID:** `ALB-<КЛАСС>-<ГГГГ>-<NNNN>` (пример `ALB-NB-2026-0417`), плюс контрольный символ. Класс — 2–3 буквы (NB ноутбук, MB мебель, KL ключ, KU кулер). ID «немой»: по нему нельзя понять ни владельца, ни цену. Инвентарный номер бухгалтерии допустимо дублировать текстом рядом с кодом — глазами, не в коде.

## 3. Сценарии применения

| Что маркируем | Что в коде | Кто сканирует | Что после скана | ПДн | Приоритет |
|---|---|---|---|---|---|
| Ноутбук, монитор, техника у работника | ID + ссылка на карточку | ИТ, кладовщик | Открывается карточка: статус, дата выдачи, номер ведомости | Нет (держатель — только в базе) | 1 |
| Мебель, рабочее место | ID мебели / ID места | Комиссия по инвентаризации | Отметка «найдено» в ведомости пересчёта | Нет | 2 |
| Ключи, пропуска (носитель, не сам пропуск) | ID брелока | Дежурный, охрана | Журнал выдачи/сдачи ключа | Нет — ФИО не в коде | 2 |
| Кулер | ID кулера + ссылка на форму заявки | Любой работник | Форма «заказать воду» с уже подставленным кулером и адресом | Нет | 1 |
| Полка/ячейка склада | ID места хранения | Кладовщик | Список того, что числится на полке | Нет | 1 |
| Коробка/партия расходников | ID партии | Кладовщик | Остаток, списание | Нет | 3 |
| Картридж (оборотный) | ID картриджа | ИТ | Отметка «установлен/сдан на утилизацию» | Нет | 3 |
| Обходной лист при увольнении | ID работника-заявки (обезличенный) | Кладовщик, ИТ, АХО | Список числящихся за человеком позиций к сдаче | Ссылка ведёт в закрытую базу, в коде ПДн нет | 1 |
| Ведомость выдачи (бланк) | Номер ведомости | Кадры, бухгалтерия | Быстрый поиск скана подписанного бланка | Нет | 2 |
| Памятка работнику | Ссылка на публичную форму заявки/FAQ | Работник | Открывается форма заявки на ТМЦ и воду | Нет | 1 |
| Инструмент, приборы | ID + ссылка | Мастер | Дата поверки/ТО, кто держит | Нет | 3 |
| Аптечка, огнетушитель | ID | Ответственный | Срок годности, дата проверки | Нет | 2 |

## 4. Инвентаризация со сканером

- Порядок инвентаризации — **ФСБУ 28/2023** (утв. приказом Минфина от 13.01.2023 № 4н), обязателен с 01.04.2025. Маркировка сам порядок не меняет, но снимает ручное переписывание и ошибки в номерах. [ЗАКОН]
- **Чем сканировать:** старт — обычный телефон (камера читает QR без приложения). ТСД (терминал сбора данных) нужен только при тысячах позиций, работе в холоде/цехе и штрихкодах вместо QR. [ПРАКТИКА]
- **Минимум, чтобы заработало без большой системы:** таблица «ID — объект — место — держатель» (Excel/Google Sheets), офлайн-генератор QR из соседнего проекта, принтер этикеток, лист сверки. Итог — два столбца: «числится» и «отсканировано».
- Расхождения всё равно оформляются документами инвентаризации — скан их не заменяет.

## 5. Печать и наклейки

| Куда | Что клеить |
|---|---|
| Металл (шкафы, стеллажи, техника) | Полиэстер/полипропилен, стойкий к спирту и трению; хорошо держит |
| Пластик (корпуса, кулеры) | То же, но обезжирить; не на текстурированный «шагрень» — отходит |
| Ткань спецодежды | Наклейка не живёт. Только термотрансфер, вшивной ярлык или метка на шкафчике/комплекте |
| Стекло, полированные поверхности | Держится, но заметно — клеить на нижнюю/тыльную грань |

- **Минимальный размер QR:** 20×20 мм для телефона с 10–15 см; мельче — только при хорошей печати и коротком ID. Обязательно белое поле вокруг кода.
- **Нельзя клеить:** на вентиляционные решётки, на подвижные части, на шильдики с серийным номером и маркировкой производителя, на нагревающиеся зоны, на СИЗ в местах защитного слоя, на арендованное/чужое имущество без согласия владельца.
- Термобумага (чековая) выцветает за месяцы — не годится.

## 6. Связка с увольнением

- Обходной лист **не предусмотрен ТК РФ** — это локальный документ; задерживать расчёт и выдачу документов из-за него нельзя. [ЗАКОН]
- Скан ID работника-заявки открывает готовый список числящихся позиций — кладовщик отмечает сдачу, а не переписывает наименования. Экономия — основная.
- **Почему код не отменяет подпись:** сканирование фиксирует факт в базе, но не является ни первичным документом, ни доказательством согласия. Материальная ответственность и взыскание ущерба (ст. 248 ТК РФ) опираются на подписанные документы — ведомость, договор о матответственности, акт. Подпись в ведомости остаётся. [ЗАКОН]

## 7. Чего делать не надо

| Не надо | Причина |
|---|---|
| Класть ФИО, табельный номер, телефон в QR | Утечка ПДн, метку фотографируют посторонние |
| Печатать стоимость на наклейке | Наводка для хищения, цифра быстро устаревает |
| Считать скан заменой подписи | Не первичный документ; в споре о матответственности не работает |
| Клеить один код на комплект «ноутбук + сумка + мышь» | При частичной сдаче непонятно, что вернули |
| Переиспользовать ID выбывшего объекта | Ломает историю и сверку с бухгалтерией |
| Запускать сразу ТСД и «систему» | Оборудование без чистого реестра ID не даёт эффекта |

## ▶ Что запустить на первой неделе

1. **QR на кулерах** — код ведёт на форму заявки на воду с подставленным номером кулера. Без ПДн, без оборудования.
2. **QR на памятке новичка** — ссылка на публичный FAQ «что получаешь / что сдаёшь / как заказать». Печать на обычном принтере.
3. **QR на полках склада** — код ведёт на список позиций полки в общей таблице. Даёт готовый реестр ID под будущую инвентаризацию.

**Уточнить у бухгалтерии:** формат инвентарного номера, порог отнесения к ОС, правила повторного использования номеров. **Уточнить в локальном акте:** форма ведомости выдачи, состав обходного листа, ответственный за маркировку.
